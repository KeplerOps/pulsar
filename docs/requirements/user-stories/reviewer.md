# Reviewer — User Stories

## UC-R1: Open a specific scene by URL

- As a Reviewer, I paste a workbench URL and land on the exact target
  so that I do not navigate from the start.

## UC-R2: Step through a scene with scrub controls

- As a Reviewer, I open a scene in `mode=scrub` and step through
  beats so that I can inspect timing.

## UC-R3: Capture a screenshot for comparison

- As a Reviewer, I open a scene in `mode=screenshot` so that I
  capture a deterministic image for comparison.

## UC-R4: Read prompter content for a scene

- As a Reviewer, I open `mode=prompter` so that I read captions
  without rendering visuals.

## UC-R5: Loop a scene for visual inspection

- As a Reviewer, I open a scene in `mode=loop` so that I inspect
  motion repeatedly.
